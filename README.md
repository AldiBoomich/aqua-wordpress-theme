# Aqua — WordPress theme for a drinking water delivery business

A custom WordPress theme for a premium water delivery brand: light, quiet design built around one idea —
living water — and a fully editable, client-friendly admin. Every text, image, price and link is managed
from WordPress, no code changes needed.

**Live demo:** https://aqua-drop.shop/ (a portfolio concept, not a real business)

## Highlights

- **Design system** — tokens for color, type, spacing, radii, elevation and motion (`src/css/tokens.css`,
  documented in `DESIGN.md`); one BEM file per component in `src/css/blocks/`.
- **Fully editable with ACF PRO** — homepage blocks, header, footer, contacts, social links, map, 404 page and
  every interface label (Theme Settings → Labels). Field groups are stored as Local JSON (`acf-json/`).
- **Modern front-end build** — Vite bundles the CSS and ES-module JS into `assets/dist/` (committed, so the theme
  deploys as a plain zip). No jQuery, no CSS framework.
- **Accessible** — skip link, keyboard-friendly menus with real buttons, focus kept inside the full-screen menu,
  visible focus rings, WCAG AA contrast, one `<h1>` per page, `prefers-reduced-motion` support.
- **Fast** — self-hosted variable font with metric-matched fallback (no layout shift), deferred scripts,
  animations on transform/opacity only, motion paused off-screen.
- **Living water** — WebGL ripples over the hero photo (rendered off the main thread, capped at ~60 frames
  per second on high-refresh screens), a pinned "7 stages" filtration scene, a bottle shelf that slides
  sideways, liquid line icons and bottles that tilt with the pointer or the phone, and a footer wordmark that
  fills with water. Every effect has a static fallback for `prefers-reduced-motion` and weaker devices.
- **Page transitions** — cross-document View Transitions with prefetch on hover; a drop cursor and magnetic
  buttons for mouse users. All switchable in Theme Settings → Motion.
- **Contact Form 7** — contact and newsletter forms styled to match the design, errors announced at the field,
  focus moved to the first field that needs fixing.
- **Portfolio mode** — a "Concept project" notice, demo forms that send nothing and `noindex`, all toggled in
  Theme Settings → Portfolio.
- **Client help** — "How to edit this website" dashboard widget and hints next to every field.

## Tested on

Chrome and WebKit (the Safari engine), on 15 screen setups from a 360 px Android phone to a 2560 px monitor:
phones at 2–3× pixel density, a phone turned sideways, iPad portrait and landscape, laptops and desktops.
No horizontal scrolling, one `<h1>` per page and no script errors on any of them.

## Requirements

- WordPress (tested on 7.1), PHP 7.4+ (tested on 8.4 and 8.5)
- [Advanced Custom Fields PRO](https://www.advancedcustomfields.com/pro/) 6.3+
- [Contact Form 7](https://wordpress.org/plugins/contact-form-7/)
- Node.js 20+ to rebuild the front-end (not needed on the server)

## Structure

```
acf-json/            ACF field groups (Local JSON)
src/css/             tokens, base, layout + one file per BEM block
src/js/              ES modules (header, menus, footer…)
assets/dist/         built CSS/JS + manifest (generated by `npm run build`)
assets/fonts/        Switzer (self-hosted variable font)
inc/                 assets (Vite manifest), ACF helpers and setup, icons, admin widget, menu walker
template-parts/      page sections, brand, social links
page-*.php           page templates: About, Services, Price List, Contact, Legal
DESIGN.md            the design system contract
```

## Build

```bash
npm install
npm run build     # or: npm run watch
```

## Deploy

1. `npm run build` and commit `assets/dist/`.
2. `git archive --prefix=aqua/ HEAD -o aqua.zip`
3. WordPress → Appearance → Themes → Add New → Upload → "Replace installed with uploaded".
4. If field groups changed: ACF → Field Groups → Sync.
